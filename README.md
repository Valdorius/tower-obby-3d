# 🏰 Башня Обби 3D (Tower of Obby 3D)

Кроссплатформенная 3D игра в жанре **Обби (Tower of Hell / Obstacle Course)**, разработанная для публикации на **Playgama** и web-платформах.

🎮 **[ИГРАТЬ ОНЛАЙН В БРАУЗЕРЕ (GitHub Pages)](https://valdorius.github.io/tower-obby-3d/)**

---

## 🕹 Управление

### 💻 На компьютере (ПК):
* **W, A, S, D** / Стрелки — Перемещение персонажа
* **ПРОБЕЛ** — Прыжок
* **SHIFT** — Спринт / Ускорение
* **Мышь (зажать)** — Свободное вращение 3D камеры (колесико — зум)
* **R** — Быстрый респаун на чекпоинт

### 📱 На смартфонах и планшетах:
* **Левый виртуальный джойстик** — Бег во всех направлениях
* **Свайп по правой части экрана** — Плавное вращение камеры вокруг героя
* **Кнопка ⬆️** — Прыжок
* **Кнопка 🔄** — Респаун на чекпоинт

## 🚀 Архитектура и технические особенности

* **Модульная архитектура:**
  - `constants.js` — Глобальная конфигурация башни (`TOWER_CONFIG`), физики игрока и параметров рекламы без магических чисел.
  - `sound.js` — Синтезатор звуков на Web Audio API с Master Gain для мгновенного глушения при показе рекламы.
  - `bridge.js` — Интеграция Playgama Bridge v2.4.0 по спецификации: события `REWARDED_STATE_CHANGED` и `INTERSTITIAL_STATE_CHANGED`, безопасное сохранение в облако (`storage.set([keys], [values])`), таблица рекордов (`leaderboards.setScore`), синхронизация с `localStorage` и автономный режим.
  - `character.js` — 3D-персонаж со скелетным ригом и процедурной анимацией бега/прыжков/покоя.
  - `tower.js` — Генератор 20 уникальных этажей, лазерных оград, спиннеров, исчезающих платформ и вершинного трофея.
  - `game.js` — Игровой цикл, обработка ввода, камера и управление состоянием.
* **Физика без туннелирования (Substepping & Swept AABB):**
  - Разделение каждого кадра на подшаги до 16 мс с непрерывной проверкой пересечения вертикального отрезка движения (Swept landing check). Игрок не пролетает сквозь платформы даже при падении со скоростью 38 м/с и просадках FPS.
* **Coyote Time и Jump Buffer:**
  - *Coyote Time (0.15с)*: возможность совершить прыжок в течение 150 мс после схода с платформы.
  - *Jump Buffer (0.15с)*: предварительный ввод прыжка перед касанием платформы с мгновенным исполнением в момент приземления.
* **Оптимизация памяти (Zero Allocation в цикле кадров):**
  - Полное устранение выделений памяти (`new Vector3`, `worldToLocal(clone())`) в горячих циклах физики, коллизий и камеры.
  - Ограничение `pixelRatio` до 1.5 и оптимизированные тени `PCFShadowMap` для стабильных 60 FPS на смартфонах.
* **Честный таймер с накоплением времени:**
  - Таймер учитывает только активное игровое время и автоматически встает на паузу во время рекламы и сворачивания вкладки браузера (`document.hidden`).
* **Монетизация Playgama:**
  - Rewarded-пропуск сложного этапа (`skip_floor`) с выдачей награды строго по событию `rewarded`.
  - Межстраничная реклама (`floor_completed`) каждые 4 пройденных этажа с кулдауном не чаще 70 секунд.
  - Rewarded-удвоение монет (`unlock_skin`) на экране победы.
  - Межстраничная реклама победы (`game_win`).
* **Вес:** < 1 МБ, запуск без сторонних серверов на любых устройствах.
