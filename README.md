# 🏰 Башня Обби 3D (Tower of Obby 3D)

Кроссплатформенная 3D игра в жанре **Обби (Tower of Hell / Obstacle Course)**, разработанная для публикации на **Playgama** и web-платформах.

🎮 **[ИГРАТЬ ОНЛАЙН В БРАУЗЕРЕ (GitHub Pages)](https://valdorius.github.io/tower-obby-3d/)**

---

## 🕹 Управление

### 💻 На компьютере (ПК):
* **W, A, S, D** / Стрелки — Перемещение персонажа
* **ПРОБЕЛ** — Прыжок
* **SHIFT** — Спринт / Ускорение
* **Мышь (зажать)** — Свободное вращение 3D камеры (колесико — зум)
* **R** — Быстрый респаун на чекпоинт

### 📱 На смартфонах и планшетах:
* **Левый виртуальный джойстик** — Бег во всех направлениях
* **Свайп по правой части экрана** — Плавное вращение камеры вокруг героя
* **Кнопка ⬆️** — Прыжок
* **Кнопка 🔄** — Респаун на чекпоинт

## 🚀 Технические особенности
* **Движок:** Three.js (WebGL 3D, мягкие тени, оптимизированный рендеринг).
* **Аудио:** Встроенный аудио-синтезатор на Web Audio API (ноль внешних аудио-файлов, мгновенная загрузка).
* **Playgama Bridge:** Полная интеграция SDK Playgama Bridge v2 (`game_ready`, Rewarded Ads для пропуска этапов, Interstitial Ads, сохранение прогресса).
* **Вес:** < 1 МБ (запускается без задержек на любых устройствах).
